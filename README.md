Streamlit 交互式驾驶舱。

**日期筛选**：采用「快捷范围预设 + 两个独立日期选择器」方案 ——



* 快捷范围一键切换：全年 / 上半年 / 下半年 / 第一季度～第四季度 / 近 30 天 / 自定义；

* 开始日期、结束日期两个独立选择器可自由指定任意区间，反向选择会自动交换；

* 预设通过 `on_change` 回调写日期，仅在预设被点击时触发，手动点选日期不会被覆盖；

  ② 程序化写值后残留旧内部状态，下一次手选日期会把另一字段重置回初始值，

  已通过「预设点击后给日期控件更换 key 强制重挂载」规避，并经浏览器实测验证。

## 数据说明



* 数据来源：天气后报（[tianqihoubao.com](https://tianqihoubao.com)）汉中市 2025 年 1 月 1 日～12 月 31 日逐日监测值

  （24 小时均值），站点为汉中市国控 / 省控监测站综合值。

* 指标：AQI、质量等级、PM2.5、PM10、NO2、SO2、CO、O3。

* 等级划分依据《环境空气质量指数（AQI）技术规定》（HJ 633—2012）。

* 核验：与官方公开口径基本一致（2025 年汉台区优良率 87.9%、PM2.5 年均 33.72 ug/m3；

  本数据优良率 89.0%、PM2.5 年均 35.87 ug/m3，含县域站点差异）。

## 主要结论



* 全年优良天数 325 天，优良率 89.0%，年均 AQI 63.9，空气质量总体良好。

* 冬季（12–2 月）颗粒物浓度最高，1 月 AQI 月均 139，出现多轮静稳天气重污染过程；

  夏季（6–9 月）空气质量最好。

* 非优良日首要污染物：PM2.5 90 天（冬季为主）、O3 79 天（夏季为主）、PM10 44 天（春季沙尘为主）。

* 4 月 12 日出现沙尘天气（AQI 300、PM10 1302 ug/m3），为全年最重污染过程。

* PM2.5 与 AQI 相关系数 0.95，是 AQI 的主导因子；PM2.5 与 O3 呈负相关（-0.25）。
